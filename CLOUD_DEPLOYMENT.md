# Serviço online gratuito

- Interface: https://joaopedroparreira.github.io/Transcripts/
- API: https://fio-transcripts-api.onrender.com
- Render: serviço fio-transcripts-api, plano Free de 0 USD/mês.
- Variáveis privadas: TRANSCRIPT_PROVIDER=supadata e SUPADATA_API_KEY (só no Render).
- Supadata: plano Free, 100 créditos/mês; sem plano pago ou auto-recharge ativado.
- Teste real em 27/10/2026: HTTP 200, português, 2 260 segmentos do vídeo reportado pelo utilizador.
- API direta do YouTube no Render devolveu IpBlocked; por esse motivo foi substituída pela integração Supadata, aprovada pelo utilizador incluindo a política de cache.
- Resultados aparecem na página do GitHub, sem depender do computador do proprietário.
- Se a língua original for ambígua entre várias faixas, o utilizador deve selecionar a língua do vídeo.
- Não há armazenamento de transcrições na aplicação; os fornecedores têm políticas próprias de registos/cache.

Nunca ativar pagamentos, auto-recharge, proxies pagos ou APIs pagas sem novo pedido explícito.
